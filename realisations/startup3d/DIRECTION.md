# Startup3D — direction du site

**Idée** : la maquette d'architecte. Le thème clair de la page est le jour de l'agence, le thème sombre sa nuit,
comme le thème automatique de l'app. Un curseur d'heure fait passer la scène du jour à la nuit.

- **Visuels** : captures réelles de l'app (build local, données de démonstration), jour et nuit.
- **Typographies** : Red Hat Display et Red Hat Mono. Auto-hébergées, licence OFL.
- **Démonstrations** : repères sur la scène (ce que chaque objet ouvre) ; mode aménagement rejoué sur un plan
  isométrique en SVG, avec les règles de l'app (chevauchement, murs, accès depuis la porte calculé par
  recherche de chemin) ; cycle d'une mission d'agent IA.
- **Film** (`#film`, « 00 Le film ») : 35 s en 16:9, avec musique originale. Le sol isométrique qui se dessine,
  l'agence de jour puis le soir (l'horloge défile), les projets, le planning, les finances, les niveaux et le thème
  clair. Fabriqué par `outils/films/presentations/startup3d.html` ; lecteur commun `assets/js/film.js`.
